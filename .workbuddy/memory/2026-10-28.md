# 2026-10-28

## CI/CD 部署配置（.github/workflows/deploy.yml）
- 项目为 RuoYi-Vue3 前端（Vue 3.5 + Vite 6.4，history 路由，生产 API 前缀 `/prod-api`，VITE_BUILD_COMPRESS=gzip）。
- 重写 deploy.yml 为两段式流水线：
  - job `build`：checkout → setup-node@v4(Node 20, npm cache) → `npm ci` → `npm run build:prod` → 校验 `dist/index.html` → upload-artifact@v4。
  - job `deploy`：download-artifact@v4 → 校验 DEPLOY_PATH 安全性 → easingthemes/ssh-deploy 只上传 `dist/`（`SOURCE: dist/`，`--delete`）。
- 触发：push main（忽略 md/LICENSE 变更）+ workflow_dispatch；`concurrency` 使新任务取消旧任务。
- 所需 Secrets：DEPLOY_SSH_KEY / DEPLOY_HOST / DEPLOY_USER / DEPLOY_PATH（可选 DEPLOY_PORT，默认 22）。
- 已本地验证：`npm ci --dry-run` lock 一致；`vite build` 可正常产出 442 文件、index.html 5422B。

## 服务器侧（宝塔）
- 纯静态 SPA，应在「网站 → HTML项目（静态站点）」建站，不要用 Node项目（宝塔 Node项目列表为空属正常，无需添加）。
- 站点根目录 = DEPLOY_PATH，需 nginx `try_files $uri $uri/ /index.html`（history 路由刷新 404）+ `/prod-api` 反代后端 + `gzip_static on`（dist 内已有 .gz 预压缩文件）。

## 环境注意
- 本地沙箱对批量删除（>50 文件/回合）有 safe-delete 拦截，`vite build` 清空 dist 会报 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`；规避方式：`vite build --outDir dist-tmp` 后用 robocopy /MIR 覆盖回 dist。
